# Campus Notes Application

## Description
Campus Notes is a simple learning application built using
Node.js, Express, HTML, CSS, JavaScript, and JSON.

## Technologies Used
- Node.js
- npm
- Express.js
- HTML
- CSS
- JavaScript
- JSON

## Installation
Install the project dependencies:

npm install

## Run the Application
Start the server:

npm start

Open the application in your browser:

http://localhost:8001

## API Endpoint
GET /api/notes

This endpoint returns study notes stored in sample-notes.json.
